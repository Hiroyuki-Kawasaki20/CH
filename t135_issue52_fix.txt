【問題】
  _serialize_lanes_final() は、同一レーン内で時間帯が重複する山を
  後ろ倒し（直列化）するが、後ろ倒し後に締切を超過していないかの
  再チェックを行わなかった（後ろ倒し後の締切再チェック欠如）。

  結果: 直列化によって押し出された山が締切を超過しても検出されず、
        そのまま出力に含まれる問題（Issue #52）。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【修正内容】

ファイル: src/services/process_assigner.py
関数:     _legacy_assign_processes_by_arrival_time() 内
          ネスト関数 _serialize_lanes_final()

修正方針:
  直列化ループ内で後ろ倒しを適用する前に、その後ろ倒しが
  当該山の締切を超過させるかを事前チェックする。
  超過する場合は後ろ倒しをスキップし、元の開始時刻を維持する。
  （物理的な重複は残るが、締切違反を新たに生成しない）

適用条件（全て満たす場合のみスキップ）:
  1. OVERFLOW 工程以外（OVERFLOWは本来超過するため除外）
  2. 当該山が現在の開始時刻では締切内である
  3. 後ろ倒し後の完了時刻が締切を超過する

変更箇所 (差分イメージ):
  # 従来
  if candidate > int(current_start):
      new_start = _adjust_start_for_breaks(candidate, work_dur)
      rr["実開始時間"] = _seconds_to_hhmm(new_start % 86400)
      ...

  # 修正後
  if candidate > int(current_start):
      new_start = _adjust_start_for_breaks(candidate, work_dur)
      # Issue #52 fix: 後ろ倒しで締切超過するなら後ろ倒しをスキップ
      if ddl is not None and proc_label != PROC_OVERFLOW:
          if currently_ok and push_would_violate:
              prev_end = cur_end; continue   # ← スキップ
      rr["実開始時間"] = _seconds_to_hhmm(new_start % 86400)
      ...
