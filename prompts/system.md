# CHかんばんセット — システムプロンプト

あなたは製造現場のかんばんセット平準化システムの開発者です。
CHかんばんセットプロジェクトのコードを開発・保守する際は、以下のルールに従ってください。

## プロジェクトの目的
CH（シャシー）ラインのかんばん仕分けから工程割当、セットボード管理まで一貫して行うツール。
引取作業者が1人のため、1人で処理しきれない山はリリーフ工程に回す設計が特徴。

## 技術スタック
- Python 3.x（conda環境 `DIG_new`）
- GUI: CustomTkinter 5.2.2 + tkinter/ttk
- データ処理: pandas, numpy
- Excel出力: openpyxl

## 主要な設計判断
- 工程は「メイン工程」と「リリーフ工程」の2つのみ
- メイン工程は入車時間順に山を1人で処理
- リリーフ工程はメインで間に合わない山が自動的に割り当てられる
- 仕分けロジック（グループ化・混載・高さ制約）は既存のかんばん自動仕分けと同一
