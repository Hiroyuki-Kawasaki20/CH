================================================================================
        CHかんばんセット — 別PCへの環境構築手順書
================================================================================

【はじめに】
このドキュメントに従って、Pythonとライブラリをインストールすれば、
別のPCでもCHかんばんセットを起動・動作させることができます。


================================================================================
【必要なもの】
================================================================================

事前に用意するもの：
  1. CHかんばんセットのソースコード一式（このフォルダ全体）
  2. インターネット接続（Miniconda・ライブラリダウンロード用）
  3. 管理者権限でコマンドを実行できるPC


================================================================================
【手順1：Minicondaのインストール】
================================================================================

Miniconda とは、Python の作業環境を簡単に作れるツールです。

★ ステップ1-1: Minicondaをダウンロード
  
  公式サイト：
  https://docs.conda.io/projects/miniconda/en/latest/

  Windows用インストーラーをダウンロードしてください。
  「Miniconda3 Windows 64-bit」をおすすめします。

★ ステップ1-2: インストーラーを実行

  1. ダウンロード したインストーラーをダブルクリック
  2. 「Next」→「I Agree」→「Next」
  3. 「Just Me (recommended)」を選択 → 「Next」
  4. インストール先フォルダはデフォルトのまま → 「Next」
  5. 「Install」ボタンをクリック
  6. インストール完了後、「Finish」をクリック

★ ステップ1-3: PowerShell を再起動

  Miniconda をインストール後は、PowerShell を一度閉じて、
  新しく開いてください（環境変数が反映されるため）。


================================================================================
【手順2：ソースコードの配置】
================================================================================

★ フォルダの配置場所

  C:\Users\【あなたのユーザー名】\DIG_Project\CHかんばんセット\

  例）
  C:\Users\taro\DIG_Project\CHかんばんセット\

このフォルダの中に以下が入っていることを確認してください：
  ✓ src/          （Pythonコード）
  ✓ config/       （設定ファイル）
  ✓ requirements.txt
  ✓ run_ch_kanban.bat
  ✓ その他のファイル・フォルダ


================================================================================
【手順3：Conda環境の作成】
================================================================================

Python専用の「作業部屋」を作ります。
これにより、このアプリ用のライブラリを他のプログラムと分けて管理できます。

★ 手順：

  1. PowerShell を開く
     [スタートメニュー] → 「PowerShell」と入力 → クリック

  2. 次のコマンドを実行（全文をコピペしてEnter）

  ┌─────────────────────────────────────────────────────────────────┐
  │ conda create -n DIG_new python=3.11                             │
  └─────────────────────────────────────────────────────────────────┘

  3. 途中で「Proceed ([y]/n)?」と聞かれたら、「y」を入力してEnter

  4. 完了まで待つ（2～5分程度）

★ インストール完了の目安：
  「(base)」の表示は変わらず、エラーが出なければOK


================================================================================
【手順4：ライブラリのインストール】
================================================================================

CHかんばんセットに必要なライブラリをインストールします。

★ 手順：

  1. PowerShell で、ソースコードのフォルダに移動

  ┌─────────────────────────────────────────────────────────────────┐
  │ cd C:\Users\【あなたのユーザー名】\DIG_Project\CHかんばんセット │
  └─────────────────────────────────────────────────────────────────┘

  例）
  cd C:\Users\taro\DIG_Project\CHかんばんセット

  2. Conda環境を有効化（「DIG_new」環境に切り替え）

  ┌─────────────────────────────────────────────────────────────────┐
  │ conda activate DIG_new                                          │
  └─────────────────────────────────────────────────────────────────┘

  ※ プロンプトが「(base)」から「(DIG_new)」に変わります

  3. ライブラリをインストール

  ┌─────────────────────────────────────────────────────────────────┐
  │ pip install -r requirements.txt                                 │
  └─────────────────────────────────────────────────────────────────┘

  4. 完了まで待つ（2～10分程度、ネット速度に依存）

★ インストール完了の目安：
  最後に「Successfully installed」と表示されたらOK


================================================================================
【手順5：設定ファイルのパス修正】★最重要・つまずきやすい
================================================================================

このステップが最も重要です。正しく修正しないとアプリが動きません。

★ ファイルを開く：

  config/ch_kanban_settings.json をテキストエディタで開いてください
  （メモ帳でもVS Codeでも構いません）

  パス：C:\Users\【あなたのユーザー名】\DIG_Project\CHかんばんセット\config\ch_kanban_settings.json

★ 修正が必要な部分：

  ┌─────────────────────────────────────────────────────────────────┐
  │ "base_dir": "C:\\Users\\【あなたのユーザー名】\\...             │
  │ "export_dir": "C:\\Users\\【あなたのユーザー名】\\...           │
  └─────────────────────────────────────────────────────────────────┘

現在のファイルの内容は以下のようになっています：

  ┌─────────────────────────────────────────────────────────────────┐
  │ {                                                               │
  │   "base_dir":                                                   │
  │     "C:\\Users\\1588386\\トヨタ自動車株式会社\\資材物流課...   │
  │     ...発注情報_河崎",                                          │
  │   "export_dir":                                                 │
  │     "C:\\Users\\1588386\\トヨタ自動車株式会社\\資材物流課...   │
  │     ...テスト_河崎",                                            │
  │   ...                                                           │
  │ }                                                               │
  └─────────────────────────────────────────────────────────────────┘

★ 修正方法：

  1. base_dir を修正

     【修正前】
     "base_dir": "C:\\Users\\1588386\\トヨタ自動車株式会社\\資材物流課　車体部　連絡・共有 - 発注情報_河崎"

     【修正後】
     "base_dir": "C:\\Users\\【あなたのユーザー名】\\...データを読み込むフォルダ..."

     例）
     "base_dir": "C:\\Users\\taro\\Downloads\\データ"

     ※ バックスラッシュは「\\」（2つ）でお願いします
     ※ パスは、実際にあるフォルダを指定してください

  2. export_dir を修正

     同様に、export_dir も修正してください

     【修正後の例】
     "export_dir": "C:\\Users\\taro\\Downloads\\出力"

★ パス指定のコツ：

  • Windows の「エクスプローラ」でフォルダを右クリック
    → 「ファイルのパスをコピー」を選ぶと、パスをそのまま貼付できます
  • その際、「\\」に変換する必要があります（「\」を「\\」に）

★ 修正が終わったら：

  ファイルを保存（Ctrl+S）して閉じてください

  │ python src/app/gui.py                                           │

★ 起動成功の確認：

  CHかんばんセットのGUIウィンドウが開きますか？

【トラブルシューティング】
================================================================================

★ Q1: 「python が見つからない」というエラーが出た

  A: Miniconda がインストール されていないか、
     PowerShell が再起動されていない可能性があります。

    1. Miniconda がインストール されているか確認
       コントロールパネル → プログラムの追加と削除で「Miniconda3」が入っているか確認

    2. PowerShell を再起動

    3. もう一度コマンドを実行


★ Q2: 「ライブラリが見つからない」というエラーが出た

  A: ライブラリがインストール されていない可能性があります。

    1. 「conda activate DIG_new」で正しい環境に切り替えたか確認
       プロンプトが「(DIG_new)」になっているか確認

    2. もう一度「pip install -r requirements.txt」を実行


★ Q3: 「ファイルが見つからない」というエラーが出た

  A: 設定ファイル (config/ch_kanban_settings.json) の
     パスが間違っている可能性があります。

    1. 【手順5】を確認して、base_dir と export_dir を再度修正してください
    2. パス内に「\\」が正しく入っているか確認
    3. 指定したフォルダが実際に存在するか確認


★ Q4: 「permission denied」というエラーが出た

  A: PowerShell の実行ポリシーが制限されている可能性があります。

    1. PowerShell を管理者権限で開く
    2. 以下を実行：
       Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

    3. 「Y」を入力してEnter


★ Q5: アプリが起動したが、GUIが表示されない

  A: customtkinter のインストール 後、
     Python を再起動する必要があります。

    1. PowerShell を一度閉じる
    2. 新しく PowerShell を開く
    3. もう一度アプリを起動


★ Q6: ConDA コマンドが見つからないと言われた

  A: PowerShell の実行ポリシーが制限されている可能性があります。

    1. PowerShell を管理者権限で開く
    2. 以下を実行：
       Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

    3. PowerShell を再起動

【補足】
================================================================================

★ Python バージョンについて
  このプロジェクトは Python 3.8 以上で動作します。
  推奨は Python 3.11 です（現在の環境で動作確認済み）。

★ conda環境について
  「conda activate DIG_new」で環境を切り替えることで、
  このアプリ用のライブラリを、他のPythonプログラムと
  分けて管理しています。

★ run_ch_kanban.bat について
  このファイルは自動的に conda環境を有効化して
  アプリを起動するスクリプトです。
  最も簡単な起動方法はこのバッチファイルをダブルクリックすることです。

★ さらに詳しい情報
  プロジェクト内の以下のドキュメントをご覧ください：
  - docs/利用マニュアル.md （操作方法）
  - docs/仕分け・割り振りルール.md （ビジネスロジック）
  - docs/起動・exe化ガイド.md （スタンドアロン化）

【サポート情報】
================================================================================

トラブルが解決しない場合は、以下を確認してください：

1. PowerShell が管理者権限で実行されているか
2. Miniconda が正しくインストール されているか（conda --version で確認）
3. ネット接続が正常か（pip install 時にファイルダウンロード）
4. config/ch_kanban_settings.json のパスが正しいか

それでも解決しない場合は、システム管理者に相談してください。
