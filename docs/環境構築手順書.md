# CHかんばんセット 別PCへの環境構築手順書

このドキュメントに従って Python とライブラリをインストールすれば、別のPCでも CHかんばんセットを起動・動作させることができます。

- 日常の起動方法・exe配布は [起動・exe化ガイド.md](起動・exe化ガイド.md) を参照してください。
- 操作方法は [利用マニュアル.md](利用マニュアル.md)、業務ロジックは [仕分け・割り振りルール.md](仕分け・割り振りルール.md) を参照してください。

## 0. 必要なもの

| # | 準備するもの | 備考 |
|---|---|---|
| 1 | CHかんばんセットのソースコード一式 | このフォルダ全体 |
| 2 | インターネット接続 | Miniconda・ライブラリのダウンロード用 |
| 3 | コマンドを実行できるPC | 一部手順で管理者権限が必要 |

前提バージョン: **Python 3.11**（`3.11.14` で動作確認済み）。conda環境名は **`DIG_new`** です。`run_ch_kanban.bat` がこの環境名を前提にしているため、変更しないでください。

## 1. Miniconda のインストール

Miniconda は Python の作業環境を簡単に作れるツールです。

### 1.1 ダウンロード

公式サイト: <https://docs.conda.io/projects/miniconda/en/latest/>

Windows 用インストーラー「Miniconda3 Windows 64-bit」を選びます。

### 1.2 インストーラーを実行

1. ダウンロードしたインストーラーをダブルクリック
2. 「Next」→「I Agree」→「Next」
3. 「Just Me (recommended)」を選択 →「Next」
4. インストール先はデフォルトのまま →「Next」
5. 「Install」→ 完了後「Finish」

### 1.3 PowerShell を再起動

環境変数を反映させるため、PowerShell を一度閉じて開き直します。

確認:

```powershell  
conda --version  
```

## 2. ソースコードの配置

配置場所:

```text  
C:\Users\<あなたのユーザー名>\DIG_Project\CHかんばんセット\  
```

次のものが含まれていることを確認します。

- `src/`（Pythonコード）
- `config/`（設定ファイル）
- `requirements.txt`
- `run_ch_kanban.bat`

## 3. Conda環境の作成

このアプリ専用の「作業部屋」を作り、他のプログラムとライブラリを分けて管理します。

```powershell  
conda create -n DIG_new python=3.11  
```

- 「Proceed ([y]/n)?」には `y` を入力して Enter
- 完了まで 2〜5分程度

## 4. ライブラリのインストール

```powershell  
cd C:\Users\<あなたのユーザー名>\DIG_Project\CHかんばんセット  
conda activate DIG_new  
pip install -r requirements.txt  
```

- プロンプトが `(base)` から `(DIG_new)` に変わります
- 完了まで 2〜10分程度（回線速度に依存）
- 最後に `Successfully installed` と表示されればOK

> 補足: リポジトリ直下の `environment.yml` / `environment-full.yml` から環境ごと再現する方法もあります（`conda env create -f environment.yml`）。本手順書では上記の `conda create` + `pip install` を標準とします。

## 5. 設定ファイルのパス修正（最重要）

`config/ch_kanban_settings.json` をテキストエディタ（メモ帳／VS Code）で開き、PCごとに次の2項目を書き換えます。**ここを直さないとアプリは動きません。**

| キー | 意味 |
|---|---|
| `base_dir` | 出荷情報CSV・出荷場一覧CSV・入車時間マスタを読み込むフォルダ |
| `export_dir` | SPO用Excelなどを出力するフォルダ |

記述例:

```json  
{  
  "base_dir": "C:\\Users\\<あなたのユーザー名>\\<データを読み込むフォルダ>",  
  "export_dir": "C:\\Users\\<あなたのユーザー名>\\<出力先フォルダ>"  
}  
```

注意点:

- バックスラッシュは **`\\`（2つ）** で書きます
- 実際に存在するフォルダを指定します
- エクスプローラでフォルダを右クリック →「パスのコピー」で貼り付け、`\` を `\\` に置換すると簡単です
- 通常運用では `base_dir` に SharePoint(OneDrive) 同期フォルダを指定します（入車時間マスタの配置ルールは [../README.md](../README.md) を参照）

修正後は保存（Ctrl+S）して閉じます。

## 6. 動作確認

### 6.1 ユニットテスト

```powershell  
conda activate DIG_new  
python -m pytest tests/unit/test_sorter.py -q  
```

### 6.2 アプリ起動

方法A（最も簡単）: `run_ch_kanban.bat` をダブルクリック

方法B（PowerShell から）:

```powershell  
conda run -n DIG_new python -m src.app.gui  
```

> `python src/app/gui.py` のようにファイルを直接指定する方法は使いません。本プロジェクトは `src` パッケージ前提のため、必ず `-m src.app.gui` 形式で起動します。

GUIウィンドウが開けば環境構築は完了です。開かない場合は次章を参照してください。

## 7. 今後の起動方法

- 通常: `run_ch_kanban.bat` をダブルクリック
- 手動:

  ```powershell  
  cd C:\Users\<あなたのユーザー名>\DIG_Project\CHかんばんセット  
  conda activate DIG_new  
  python -m src.app.gui  
  ```

起動時の自己診断やログの見方は [起動・exe化ガイド.md](起動・exe化ガイド.md) 1.2〜1.3節にまとめています。

## 8. トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| `python` が見つからない | Miniconda 未インストール、または PowerShell 未再起動 | 「プログラムの追加と削除」で Miniconda3 の有無を確認し、PowerShell を再起動して再実行 |
| `conda` が見つからない | conda が PATH に無い／PowerShell 用の初期化が未実施 | `conda init powershell` を実行して PowerShell を再起動（Anaconda Prompt からの実行でも可） |
| ライブラリが見つからない | 環境が `DIG_new` になっていない、依存が未インストール | プロンプトが `(DIG_new)` か確認し、`pip install -r requirements.txt` を再実行 |
| ファイルが見つからない | `config/ch_kanban_settings.json` のパス誤り | 5章を再確認（`\\` になっているか、フォルダが実在するか） |
| `permission denied` / スクリプト実行不可 | PowerShell の実行ポリシー制限 | 管理者権限の PowerShell で `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| 起動したが GUI が出ない | customtkinter 導入直後でプロセスが古い状態 | PowerShell を閉じて開き直し、再度起動 |
