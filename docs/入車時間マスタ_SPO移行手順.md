# 入車時間マスタ SPO移行手順

この手順は、`入車時間マスタ.xlsx` を従来配置から SharePoint(OneDrive) 同期フォルダ管理へ移行するための運用手順です。

## 1. 事前確認

- OneDriveが起動していることを確認します。
- 社内ネットワークまたはVPNに接続します。
- `config/ch_kanban_settings.json` の `base_dir` が、出荷情報CSVと出荷場一覧CSVを置いているSharePoint同期フォルダを指していることを確認します。
- 移行対象ファイル名が `入車時間マスタ.xlsx` であることを確認します。
- ExcelまたはSharePointブラウザで同ファイルを開いている利用者がいないことを確認します。

## 2. バックアップ

- 従来位置の `入車時間マスタ.xlsx` を任意のバックアップフォルダへコピーします。
- コピー後、バックアップファイルが開けることを確認します。
- バックアップには日付が分かる名前を付けます。例: `入車時間マスタ_backup_20260907.xlsx`

## 3. コピー

- `base_dir` が指すSharePoint(OneDrive)同期フォルダを開きます。
- `入車時間マスタ.xlsx` をそのフォルダ直下へコピーします。
- OneDriveの同期アイコンが完了状態になるまで待ちます。
- フォルダ内に `入車時間マスタ - コピー.xlsx` や `入車時間マスタ (競合コピー).xlsx` などがないことを確認します。

## 4. 動作確認

- ツールを起動します。
- 通常どおりデータを読み込み、入車時間マスタを参照する処理がエラーなく進むことを確認します。
- 入車時間マスタを1件編集して保存します。
- 保存後、SharePoint同期フォルダ上の `入車時間マスタ.xlsx` の更新日時が変わることを確認します。
- Excelで開き、`OData_納入先`、`NONYUHIBIN`、`入車時間`、`セットありフラグ` の列が維持されていることを確認します。

## 5. 後片付け

- 動作確認が完了したら、従来位置の `入車時間マスタ.xlsx` は誤使用防止のため保管場所へ移動します。
- すぐ削除せず、一定期間はバックアップとして残します。
- 利用者へ、今後の編集対象がSharePoint同期フォルダ上の `入車時間マスタ.xlsx` であることを周知します。

## 6. 切り戻し

- SharePoint同期フォルダにアクセスできない状態が続く場合は、バックアップした `入車時間マスタ.xlsx` を従来位置へ戻します。
- `master_path` を個別設定している場合は、設定を削除または従来位置に変更します。
- ツールを再起動し、従来位置のファイルで読み書きできることを確認します。
- SharePoint側の問題が解消したら、再度この手順で同期フォルダへ移行します。

## 7. トラブル表

| 症状 | 主な原因 | 対応 |
|---|---|---|
| `入車時間マスタ.xlsx` が見つからない | `base_dir` が違う、OneDrive未同期、ファイル名変更 | `base_dir` と同期状態を確認し、ファイル名を `入車時間マスタ.xlsx` に戻します。 |
| 保存先フォルダが見つからない | ネットワーク未接続、OneDrive停止、同期フォルダ未作成 | 社内NW/VPNとOneDrive起動状態を確認します。ツールはフォルダを自動作成しません。 |
| 保存できない | ExcelまたはSharePointブラウザでファイルを開いている | 開いている画面を閉じてから再保存します。未保存内容は `%TEMP%` の `入車時間マスタ_未保存_日時.xlsx` に退避されます。 |
| 読み込めない | Excelファイル破損、同期途中、クラウドのみ状態 | OneDriveでローカル保持にし、SharePointのバージョン履歴から復元できるか確認します。 |
| `入車時間マスタ*` の類似ファイルが表示される | OneDrive同期競合 | 最新内容を確認し、正しいファイルを `入車時間マスタ.xlsx` に統合します。 |
| 編集した内容が反映されない | 別候補のファイルを見ている | 優先順位は `master_path`、`base_dir`直下、従来位置の順です。不要な個別設定や古いファイルを確認します。 |
