# CHかんばんセット 利用マニュアル

## 0. このマニュアルについて

このマニュアルは、初めて CHかんばんセット を使う方向けの手順書です。
「どこを押せばよいか」が分かるように、操作を順番に説明します。

## 1. システムの概要（何ができるか）

CHかんばんセットは、出荷データをもとに、次の作業を自動で行うシステムです。

- かんばんを山ごとに仕分けする
- 山をメイン工程とリリーフ工程に自動で割り振る
- セットボードのあふれ山を確認する
- 引取開始時間を計算する
- セットボード画面で結果を確認する
- SPO提出用のExcelを出力する
- SPOにアップしたExcelデータをもとに、Power Appsで作業者向けに結果を表示する

### 1.1 使うと何が楽になるか

- リフト乗り降りの工数を減らせる
- 締切に間に合わない山を自動でリリーフに回せる
- 集荷が間に合うかを画面上で確認できる
- リリーフのスタート時間が明確になる

## 2. 利用前の準備（必要な環境・権限）

### 2.1 必要なもの

- Windows PC
- このシステムを起動できる環境（社内配布版またはPython実行環境）
- 入力データ一式
  - 出荷情報CSV
  - 出荷場一覧CSV
  - 入車時間マスタ（Excel）
- 出力先フォルダへの書き込み権限

### 2.2 事前チェック

作業前に、次のチェックを必ず行ってください。

- 入力ファイルが最新か
- 入車時間マスタに対象便の情報があるか
- 出力先フォルダに保存できるか
- 同じファイルをExcelで開いたままにしていないか

**重要:** 入力ファイルが古いと、仕分け結果が実運用と合わなくなります。

### 2.3 起動方法（Python実行環境の場合）

#### かんたん起動（推奨）

1. プロジェクト直下の [run_ch_kanban.bat](../run_ch_kanban.bat) をダブルクリックします。
2. 画面タイトル「CHかんばんセット — 仕分け・セットボード」が表示されたら起動完了です。

#### 手動起動（従来手順）

1. ターミナルを開きます。
2. 次の順で実行します。

```bash
conda run -n DIG_new python -m src.app.gui
```

3. 画面タイトル「CHかんばんセット — 仕分け・セットボード」が表示されたら起動完了です。

補足: exe配布版の作成と運用は `docs/起動・exe化ガイド.md` を参照してください。

## 3. 基本操作手順（ステップ形式）

ここでは、最もよく使う標準手順を説明します。

### ステップ1: 入車時間マスタを読み込む

1. 「入車時間設定」タブを開きます。
2. アプリ起動時にマスタは自動読込されます。
3. 必要に応じて「全受入CHからインポート」「行追加」「マスタ保存」で内容を更新します。

### ステップ2: 便名を選ぶ

1. 左側の「① 便名を選ぶ」から対象の便名を選択します。
2. 複数便をまとめて処理する場合は、複数選択します。

### ステップ3: オーダーを選ぶ

1. 左側の「② オーダーを選ぶ」から対象オーダーを選択します。
2. 受入を使う運用の場合は、受入も選択します。
3. 選択内容を追加して、一覧に入っていることを確認します。

### ステップ4: 仕分けを実行する

1. 「▶ 仕分け＆セット実行」をクリックします。
2. 実行中はタイトルが「実行中... CHかんばんセット」に変わります。
3. 完了後に「仕分け＆セット完了」のメッセージが表示されます。

### ステップ5: 結果を確認する

1. 「セットボード」タブでメイン工程とリリーフ工程を確認します。
2. ステータスバーで山数・工程別件数を確認します。
3. 締切警告が表示された場合は、対象山を優先確認します。

### ステップ6: 出力する

1. SPO用Excelは実行時に自動出力されます。
2. 未ヒットがある場合は `SPOアップロード用_未ヒット一覧.csv` が同じ出力先に作成されます。
3. 出力したSPO用Excelを所定の場所へアップロードします。
4. Power Apps画面で、作業者向けの表示内容を確認します。

## 4. よく使う機能の説明

### 4.1 CSV再読込

- ボタン: 「CSV再読込」
- 用途: 入力CSVを最新状態に更新する
- 使う場面: データ更新直後に再計算したいとき

### 4.2 自動再読込

- 項目: 「自動再読込」
- 用途: 指定した分のタイミングでCSVを自動更新する
- 使う場面: 長時間監視しながら運用するとき

### 4.3 セットボード確認

- タブ: 「セットボード」
- 内容: メイン工程 / リリーフ工程 / あふれの3レーン表示
- 確認ポイント:
  - 開始時間
  - 納入先
  - オーダー
  - パレット数
  - 引取工数
  - あふれ警告の有無

### 4.4 山の手動移動

- 機能: セットボードで山を選択し、「山を移動」ボタンでメイン/リリーフを切り替え
- 使う場面: 現場判断で担当を変更したいとき

補足: あふれ工程は締切超過時の警告レーンであり、手動移動の直接対象ではありません。

**重要:** 手動移動後は、締切超過がないか必ず確認してください。

### 4.5 Power Appsでの結果確認

- 用途: SPOにアップされたExcelデータをもとに、作業者が見やすい画面で結果を確認する
- 使う場面: 現場でメイン/リリーフの割り振り結果を共有するとき
- 確認ポイント:
  - 対象便の表示有無
  - 山番号と工程区分の一致
  - 開始時間の表示
  - 直近の更新データが反映されているか

## 5. 利用時のルール・注意事項

- 実行前に必ず対象選択（便名・オーダー・必要時は受入）を確認する
- 入車時間マスタを読み込んでから実行する
- 実行結果の警告メッセージは無視しない
- 出力ファイルを開いたまま再出力しない
- 手動移動を行った場合は、変更内容をチームに共有する

**重要:** 「選択が空です」のメッセージが出た場合、実行されていません。選択一覧に対象が入っているか確認してください。

## 6. よくあるミスと対処方法（Q&A）

### Q1. 実行ボタンを押しても動きません

- 症状: 「選択が空です。便名・受入・オーダーを追加してください。」
- 対処:
  1. 便名を選択する
  2. オーダーを選択する
  3. 必要なら受入を選択する
  4. 選択一覧に行が追加されたことを確認して再実行

### Q2. 締切警告が出ました

- 症状: リリーフに割り振っても締切に間に合わない警告が出る
- 対処:
  1. 対象山の開始時間と引取工数を確認
  2. 入車時間マスタの時刻誤りがないか確認
  3. 必要に応じて山の担当見直しを実施
  4. 変更後に再実行して再確認

### Q3. マスタ更新（インポート/保存）でエラーになります

- 症状: 「インポートエラー」または保存時エラー
- 対処:
  1. マスタファイルの場所が正しいか確認
  2. ファイルが開きっぱなしでないか確認
  3. 列名が壊れていないか確認
  4. 直らない場合は管理者へ連絡

### Q4. SPO用Excelが出力されません

- 症状: 出力完了メッセージが出ない、または出力エラーが出る
- 対処:
  1. 出力先フォルダへの権限を確認
  2. 同名ファイルを開いていないか確認
  3. ディスク容量を確認
  4. 再実行

### Q5. Power Appsに最新結果が出ません

- 症状: 実行後なのにPower Apps画面が古いまま
- 対処:
  1. 「仕分け＆セット実行」を実施し、SPO用Excelが出力されたことを確認
  2. SPOへアップロードが完了しているか確認
  3. Power Apps画面を再読み込みする
  4. 反映されない場合は、取り込み状況を管理者へ確認

## 7. 問い合わせ先・サポート

### 7.1 問い合わせ時に伝える情報

連絡時は、次の情報を先にまとめると解決が早くなります。

- 発生日時
- 便名 / 受入 / オーダー
- 画面メッセージ（そのまま）
- どの操作で発生したか
- 直前に実施した手順

### 7.2 連絡先（社内運用に合わせて記入）

- 一次窓口: 所属チームの運用担当
- 二次窓口: システム管理担当
- 連絡方法: Teams / メール / 内線

### 7.3 緊急時の対応

- 締切に影響する障害は、電話またはTeamsで即時連絡
- その後、再現手順と画面メッセージを共有
