# CHかんばんセット — 要件定義

## 1. プロジェクト概要

CHかんばんセットは、CH受入で発行されるかんばんの仕分け・工程割当・セットボード管理を行うツール。
既存の「かんばん自動仕分け」プロジェクトのロジックをベースに、CH固有の運用ルールを反映する。
詳細な工程割り振りルールは [仕分け・割り振りルール.md](仕分け・割り振りルール.md) に集約する。

## 2. かんばん自動仕分けPJとの相違点

| 項目 | かんばん自動仕分け | CHかんばんセット |
|------|-------------------|-----------------|
| 引取作業者数 | 複数（1〜4工程） | **1人のみ** |
| 工程超過時 | 2工程→3工程→4工程へ分散 | **リリーフ工程**へ回す |
| 工程構成 | 1工程/2工程/3工程/4工程 | **メイン工程/リリーフ工程/あふれ(警告)** |
| セットボード | バーチャルセットボード（別ウィンドウ） | **統合セットボード**（タブ内） |
| 出力 | SPOアップロード用Excel | SPOアップロード用Excel（工程ラベル変更） |

## 3. 機能要件

### 3.1 データ読み込み
- 出荷情報CSV（`出荷情報_CH_最新版.csv` 優先、なければ `出荷情報_全便_最新版.csv`）の読み込み
- 出荷場一覧CSV（`出荷場一覧.csv`）の読み込み
- 入車時間マスタ（Excel）の読み込み
- 配車表Excel（`Ｎ８ *.xlsm`）からのインポート
- エンコーディング自動判定（UTF-8/CP932）

### 3.2 データ正規化
- 全角→半角変換（数字、コロン）
- 納入先名・便名のエイリアス統一
- 時刻文字列の HH:MM 正規化

### 3.3 フィルタリング・選択
- 便名→受入→オーダーの階層選択
- 複数便・複数オーダーの一括選択
- まとめ選択モード（受入省略）
- 実行前に対象の直（1直 / 2直）を選択できる

### 3.4 かんばん仕分け
- PLANKANBANSU に基づくレコード展開
- 入車時間による山の分離（入車時間が異なるオーダーは別山）
- サイズ種類別グループ化（ファーストフィット）
  - 種類1: 混載可（受入キーベース）
  - 種類4: 武部専用（NONYUHIBIN主キー）
  - その他: グループ単位
- 高さ上限（DEFAULT_HEIGHT_CAP = 2450mm）

### 3.5 工程割当（CH固有）
- **メイン工程**: 作業者1人が入車時間順に山を処理
- **リリーフ工程**: メイン工程で入車時間に間に合わない山を割り当て
- **あふれ工程**: リリーフ工程でも締切に収まらない山を警告レーンへ割当
- **バッテリー交換（任意）**: チェックON時、表示/出力用の仮想山（山通番=-1, 600秒）をメイン工程へ挿入
- 割当ロジック:
    1. 新スケジューラ（EDF + 同便クラスター連続 + アイドル部分充填）で割当を試行
    2. 新スケジューラ結果が既存ロジック同等以上の場合のみ採用（劣後時は既存ロジックへフォールバック）
    3. メイン工程で間に合わない山をリリーフへ割当
    4. リリーフでも締切超過となる山をあふれへ割当
- 休憩時間の自動除外、および休憩前後の特別ルールの正本は [仕分け・割り振りルール.md](仕分け・割り振りルール.md) 4.6節・付録Aに集約する（本書では要点のみ記載）
  - 短休憩（1直 08:30-09:00 / 12:55-13:25、2直 18:45-19:15 / 23:10-23:40）: 純休憩10分＋仕分け猶予20分＝引取不可30分、再開は休憩明け+1分
  - 食事休憩（1直 10:40-11:25 / 2直 20:55-21:40）: 45分。休憩前は開始10分前までに完了、引取再開は休憩明け＋25分（`LUNCH_POST_RESUME_SECS`）

### 3.6 セットボード
- メイン/リリーフ/あふれの3レーン表示
- 「山を移動」ボタンで選択山をメイン/リリーフ間で手動切替
- 違反検出（入車時間超過）
- 操作ログの記録

### 3.7 Excel出力
- SPOアップロード用Excel（自動出力、工程=1工程/リリーフ工程/あふれ）
    - 出力は `spo_export` により、プロセス内排他 + 一時ファイル書込 + 同期安定待機で安全化
- 未ヒット一覧CSV（入車時間マスタ未マッチ時）
- 工程別かんばん明細Excel/セットボードHTMLは実装済みユーティリティ（現行GUIでは自動実行しない）
- 履歴追記は実装済みで、SPO出力時に追記可能な場合に実行

### 3.8 運用補助
- CSV再読込ボタンで入力CSVを手動再読込できる
- 自動再読込は設定した分（0〜59）で毎時実行できる
- 自動再読込の分設定は設定ファイルへ保存する
- 工程別引継ぎ時刻: 同一直での連続実行時に前回の工程終了時刻をメモリに保持
- 引継ぎ時刻は実行時の直選択（1直 / 2直）をキーに適用する
- 直が切り替わると自動的にリセットされる
- 「引継クリア」ボタンで手動リセットできる
- アプリ再起動で自動クリアされる

### 3.9 工数計算
計算式の正本は [仕分け・割り振りルール.md](仕分け・割り振りルール.md) 1節に集約する（本書は要点のみ記載。値を変更する場合は両方を同時に更新すること）。
```
引取工数 = Max移動工数 + BASE_ONE_TIME + (パレット数 - 1) × MIDDLE_WORK + パレット数 × BASE_PER_PAL
```
- `BASE_ONE_TIME` = 187.64
- `MIDDLE_WORK` = 3.247
- `BASE_PER_PAL` = 52
## 4. 非機能要件

- GUI: CustomTkinter 5.2.2 + tkinter/ttk
- フォント: Meiryo UI
- エンコーディング: UTF-8
- 実行環境: Windows / conda環境 `DIG_new`（Python 3.8以上、3.11で動作確認）
- 処理時間: 仕分け実行1秒以内（目標）
