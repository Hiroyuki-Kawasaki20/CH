## 1. 背景と目的
2026-09-30 の 18:15〜18:46 入車分（織機07便・日野02便・KVC 01/02便・高岡05便）27パレットで、アプリと作業者の手組みを比べた。

| 指標 | アプリ（main） | 作業者の手組み |
|---|---|---|
| 山の数（全体） | 10 | **9** |
| 山の数（サイズ1/21） | 7 | **6**（理論上の最少：高さ合計13,720 ÷ 上限2,450） |
| 山ごとに回るエリア数の合計 | 15 | **10** |
| 山ごとに回る列数の合計 | 20 | **13** |
| 引取工数の合計（照合待ちを除く） | 4,317秒 | **3,759秒（約9分短縮）** |

目的：作業者と同じように「取りに行く場所（エリア・列）」をまとめ、山の数と集荷の移動工数を減らす。

## 2. 用語
| 用語 | 意味 | 例 |
|---|---|---|
| エリア | ストアを「-」で区切った1つ目 | `Q10-A-24` → `Q10` |
| 列 | ストアを「-」で区切った2つ目（エリアとセットで扱う） | `Q10-A-24` → `Q10-A` |
| トラック | 入車時間が同じ便のまとまり（既存の `_truck_key`） | KVC-B7 01/02便・KVC-B3 02便・高岡05便はすべて18:46 |
| 便 | 納入先 × NONYUHIBIN下2桁 | 日野02便 |
| ローカル山 | 混載の前に作る仮の山 | |

## 3. 確認済み事項（2026-09-30 回答）
| # | 質問 | 回答 |
|---|---|---|
| 1 | KVC 01便と02便を混ぜてよいか | 入車時間が同じ（18:46）なので混ぜてよい |
| 2 | エリアまたぎ（例：Q10＋C15）はよいか | 許容。まず同じエリアを集め、高さに余裕があれば他を乗せてよい |
| 3 | Q9とQ10は別エリアか | 別エリアでよい |
| 4 | 受入はそろえるべきか | なるべくでよい。山の数が最小なのが大事 |
| 5 | KVC 01便 C15-A-1 の受入 | B7 |
| 6 | 追加要望 | Q10のA/B/D列も集約したい（集荷の移動工数を減らすため） |
| 7 | 「混載は最大3山まで」は「1山に混ぜる便は3つまで」か | 合っている。経験上それ以上になることはない |
## 4. 優先順位
1. 山の数を最小にする（最優先）
2. 同じ列（例：`Q10-A`）でまとめる
3. 同じエリア（例：`Q10`、`L12`）でまとめる
4. 2・3の中では、同じトラック（入車時間）どうしを先にまとめる
5. 受入はなるべくそろえる（山を増やしてまではそろえない）
6. 最後に、エリアをまたいで高さの空きに乗せる

## 8. 今のロジックで7山（全体10山）になる理由
| ローカル山 | 中身 | 高さ | 問題 |
|---|---|---|---|
| 日野02・特例 | Q10-A-24 | 1,000 | |
| 日野02・1 ① | Q10-A-13, A-12, A-11 | 2,250 | |
| 日野02・1 ② | Q10-A-10, B-7, D-25 | 2,000 | A・B・D列が混ざる |
| 日野02・21 ① | Q10-A-22, A-20×2, B-3 | 2,000 | A・B列が混ざる |
| 日野02・21 ② | Q10-B-B | 500 | B-3と分かれる |
| 織機07 | C15-A-3×2 | 1,500 | |
| KVC02 | C15-A-1, L12-D-8, L12-C-5 | 1,860 | C15とL12が混ざる |
| KVC01 | C15-A-1, L12-D-8 | 1,345 | C15とL12が混ざる |
| 高岡05 | C15-A-3, L12-C-5 | 1,265 | C15とL12が混ざる |

- 1巡目（アイル一致）：高さが合う相手が無く、0件
- 2巡目（制限なし）：KVC02＋Q10-B-B（2,360）、織機07＋Q10-A-24（2,500）だけが成立 → 7山
- KVC01・KVC02・高岡05は同じ18:46のトラックなのに、C15とL12が混ざったローカル山どうしでは高さの合計が2,450を超え、まとめられない
