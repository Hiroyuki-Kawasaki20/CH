# M365 Copilot用テンプレート（運用手順書自動生成）

## 使い方
- 最新の運用実態に合わせて空欄だけ埋める。
- 生成結果をそのまま配布せず、現場確認して確定版化する。

## 貼り付けテンプレート
あなたは業務運用ドキュメント作成担当です。

【目的】
CHかんばんセットの日次運用手順書を、現行仕様に沿って作成する。

【対象読者】
- 班長
- 実務担当者
- 引き継ぎ担当者

【システム概要】
- 入力: 出荷情報CSV、出荷場一覧CSV、入車時間マスタExcel、配車表Excel
- 処理: 読込・正規化・フィルタ・かんばん展開・グループ化・工程割当
- 出力: SPOアップロード用Excel、未ヒット一覧CSV
- 可視化: メイン/リリーフ/あふれ の3レーンセットボード

【固定運用ルール】
- メイン工程1名体制。
- メインで間に合わない山はリリーフへ。
- リリーフでも間に合わない山はあふれとして警告運用。
- 山の手動移動は「山を移動」ボタンで実施。
- 休憩時間ルールを時間計算に反映する。

【手順書に必ず含める章】
1. 起動前確認（ファイル配置、設定、前日残件確認）
2. 起動手順（環境、起動方法、画面確認）
3. 日次処理（データ取込から出力まで）
4. 監視ポイント（締切違反、あふれ、未ヒット）
5. 例外時対応（入力欠損、マスタ未一致、時間異常）
6. 手動介入手順（山移動、再計算、再出力）
7. 終了処理（成果物保存、ログ保全、引き継ぎ）
8. 付録（用語、問い合わせ先、チェックリスト）

【出力要件】
- 現場でそのまま読める文章で作成。
- 各章に「目的」「操作」「確認結果」「異常時対応」を含める。
- チェックリストはチェックボックス形式にする。
- 曖昧語を避け、判断基準を数値か条件で明示する。

【禁止事項】
- 現行仕様と矛盾する運用を記載しない。
- 抽象的な精神論だけで章を埋めない。
- 不明点を伏せたまま確定文を書く。
