## 推奨運用
- 1回の依頼で1テーマに限定する。
- 先頭に「固定前提（変更禁止）」を書く。
- 末尾に「未確定事項（質問）」を必ず出させる。
- 回答の妥当性を docs/requirements.md と docs/仕分け・割り振りルール.md で照合する。

## すぐ使う手順
1. 目的に合うテンプレートを開く。
2. 空欄を埋める。
3. 全文をM365 Copilotに貼る。
4. 返答を要件書と付き合わせ、差分だけ採用する。
